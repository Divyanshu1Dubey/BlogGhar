## CONTENT STANDARDS

Each article must:
✅ Answer reader's primary search intent immediately
✅ Be substantial (not thin content)
✅ Include real examples and case studies
✅ Have verifiable sources cited
✅ Contain practical implementation steps
✅ Include relevant decision frameworks or comparisons
✅ Be internally linked to relevant articles
✅ Have complete SEO metadata
✅ Be distinct from competitors' coverage
✅ Never fabricate facts, dates, or claims

## DATABASE SCHEMA

Post Model Fields Used:
- `title` - SEO-optimized title (60 chars ideal)
- `slug` - URL-friendly slug
- `content` - HTML content
- `excerpt` - Meta description text
- `seoTitle` - Meta title tag
- `seoDesc` - Meta description
- `focusKeyword` - Primary keyword
- `readTime` - Estimated reading time (minutes)
- `status` - PUBLISHED / DRAFT
- `publishedAt` - Publication date
- `categoryId` - Category reference
- `authorId` - Author reference
- `tagId` - Tag reference
